# Economy

*Status: Draft · Updated: 2026-10-14*

## Модель

Две сущности: **баланс** (валюта — «обычные фишки») и **коллекция** (конкретные фишки-предметы).

В партии каждая выбитая фишка: +1 к балансу и +1 экземпляр в коллекцию. Ставка списывается в начале. Итог партии ≈ zero-sum по балансу при равной удаче.

## Faucets (приток)

| Источник | Условие | Награда |
| --- | --- | --- |
| Ежедневная награда | раз в 24 ч | `DAILY_MIN..DAILY_MAX` + бонус за серию (до `DAILY_STREAK_CAP`) |
| Колесо фортуны | цена `WHEEL_PRICE` | 10/20/50/100 фишек или редкая фишка |
| Достижения | по прогрессу | фикс. награда за каждое |
| Продажа дубликатов | — | `chip.value * SELL_RATE` (0.5) |
| Серии коллекции | собрать все фишки серии | `25×n + 20×epic + 50×legendary` (один раз) |
| Ежедневные задания | 3 задания в сутки | 25–60 за задание |
| Кузница | дубликаты → биты/уровни | см. `design/gdd/meta.md` |

## Sinks (отток)

- Ставки в партиях
- Покупка бит (`BITAS[].price`)
- Плата за колесо (`WHEEL_PRICE = 20`)
- Очки кузницы (дубликаты сгорают при крафте/апгрейде)

## Settlement

`settleMatch(profile, state, playerIndex)`:

1. `+flippedCount` к балансу
2. `addChip()` для всех собранных + бонусных фишек
3. Обновление `stats` (партии, победы, win-streak, chipsWon/Lost, bitsCollected)
4. `checkAchievements()` и `recordLeaderboard()`

## Persistence

- `localStorage`, ключ `chips.profile.v1`, версия `PROFILE_VERSION = 2`
- Сейвы v1 читаются без потерь: `reconcile()` добавляет `bitaLevels`,
  `seriesClaimed` и `quests` дефолтами
- Мета-поля и их формулы — в `design/gdd/meta.md`

## Стартовые значения

- Стартовый баланс `STARTING_BALANCE = 100`
- Ставки `[10, 20, 50]`
- Бита: 150–800 фишек
- Кузница: 1 очко = `chip.value`, крафт = `ceil(price/5)`, апгрейд =
  `20 + 12×(level-1)`, максимум 5 уровней
