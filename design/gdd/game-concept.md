# Game Concept: CHIPS

*Created: 2026-10-14 · Status: Draft*

## Elevator Pitch

> Это веб-игра, где ты бьёшь битой по стопке дворовых фишек и выбиваешь их себе, чтобы обыграть соперника и собрать лучшую коллекцию.

## Core Identity

| Aspect | Detail |
| --- | --- |
| **Жанр** | Пошаговая аркадно-азартная мини-игра (по мотивам «соток») |
| **Платформа** | Web (кроссплатформенно: desktop, mobile, tablet) |
| **Аудитория** | Ностальгирующие взрослые + казуальные игроки |
| **Игроков** | 1v1: против ИИ и локальный хост-сит |
| **Длительность партии** | 1–3 минуты |
| **Монетизация** | Нет (внутренняя экономика) |
| **Масштаб** | Малый (MVP) |
| **Референсы** | Реальные «сотки»/кэпсы, POG, дворовые игры 90-х |

## Player Fantasy

Азарт удара, коллекционерская гордость, атмосфера двора.

## Core Loop

1. Выбор ставки и режима → 2. Череда ударов по стопке → 3. Фишки переворачиваются и уходят победителю → 4. Итоги, начисление в коллекцию, достижения → 5. Мета: покупка бит, ежедневка, колесо, продажа дубликатов.

## Стек

Phaser 3 + TypeScript + Vite — см. `docs/architecture/ADR-0001-web-stack.md`.

## MVP Scope

- Ядро матча с реалистичной моделью переворота
- 2 режима, коллекция, биты, маркет, ежедневка, колесо, достижения, рейтинг
