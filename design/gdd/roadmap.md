# Roadmap: CHIPS — от «скучно» к живому

*Created: 2026-10-16 · Status: In progress — S4 «Мета» now done, next up: S5 онлайн*

Спринты идут в порядке «эффект / затраты». Каждый спринт заканчивается
проверкой: `npx tsc --noEmit`, `npx vitest run`, `npm run test:server`,
`node scripts/smoke-online.mjs`, `npm run build`. Игровые правила остаются в
`design/gdd/*` — если механика меняется, сначала правится док, потом код.

## S1. Звук и «сок» — ✅ сделано

Проблема: в проекте не было **ни одного** звука и почти не было ощущения удара.

- `src/game/ui/Audio.ts` — синтез SFX на WebAudio, **без ассетов**:
  `click`, `open/close`, `chargeStart/Set/Stop` (живой тон заряда),
  `smash(power01)`, `flip(i)`, `crit`, `miss`, `coin`, `rare`, `buy`,
  `achievement`, `win/lose`, `turn`, `error`.
  Контекст создаётся лениво и только внутри жеста (`main.ts` вешает `unlock()`
  на первый `pointerdown`/`mousedown`/`touchstart`/`keydown`/`click`).
  `chargeSet` троттлится, чтобы не копить события в AudioParam.
- `src/game/systems/Settings.ts` — `muted` / `reduceMotion` в отдельном ключе
  `chips.settings.v1` (не в профиле: сброс сейва не должен включать звук).
  `reduceMotion` по умолчанию берётся из `prefers-reduced-motion`.
- `Fx.ts`: `hitStop()` (микро-замедление на удар), `flash()`; `shake()` и
  `flash()` уважают `reduceMotion`.
- Триггеры: кнопки и модалки (`Widgets`), меню (ежедневка, колесо, магазин),
  `MatchScene` (заряд → удар → фишки → крит/мимо → итоги → ачивки),
  `RoomScene` (то же + пинг хода).
- «Сок»: крит при ≥4 выбитых фишках (`💥 КРИТ!` + вспышка + арпеджио),
  hit-stop, вспышка на сильном ударе.
- Кнопка 🔊/🔇 в футере меню.

## S2. Механики матча — ✅ сделано

Диагноз: единственный глагол «зажал — отпустил», промах ничего не стоит
(`SmashReport.outcome === 'none'` не используется), ИИ целится рандомом,
коллекции некуда деваться.

- **«Переход»**: промах (0 переворотов за ход) даёт сопернику `+MISS.BONUS`
  (0.12) к прицелу на следующий удар, потолок — `MISS.MAX_BONUS` (0.24).
  Бонус едет поверх полосы прицела и тратится на первом же ударе получателя.
  В UI — плавашка «🎯 ПЕРЕХОД» и бейдж `🎯+%` на карточке.
- **Спец-удары с ценой в уже собранных фишках**: «точный» (2 фишки, ≥2
  переворота у прицела), «отбой» (1 фишка, соперник бьёт на 25 % слабее),
  «двойной» (1 фишка, два удара за ход). Фишки возвращаются рубашкой вниз в
  низ стопки; на добивающем ходу удар бесплатен. В UI — `MoveBar` из трёх
  пилюль с ценой и диммингом недоступных.
- **Живой ИИ**: `pickAiFocus` перебирает точки прицела по ожидаемым
  переворотам (`expectedFlips`), `pickAiPower` тянет силу степенью от
  `AI.SKILL`, `pickAiMove` тратит удары по эвристике «толстая стопка →
  двойной, тонкая → точный». Шум прицела — `AI.AIM_JITTER`.
- **Общее ядро**: `src/game/systems/MatchEngine.ts` + `server/engine.mjs`.
  `playTurn(state, rng, opts) → { reports, move, cost, missed }`,
  `smash()` оставлен тонкой обёрткой. Перемешивание — один раз за ход.
  `MAX_TURNS = 600` — предохранитель.
- **Сеть**: `move` в `match:smash`; сервер валидирует ход, цену и очередь;
  боты автоиграют спец-ударами. `RoomScene` показывает бейджи отчётов
  (`move` / `weakened` / `precise`) и модификаторы игроков.
- Проверки: `tsc` чисто, 38 клиентских тестов, 18 серверных (включая
  «боты иногда тратят спец-удары»), 23 онлайн-проверки, `npm run build`.
- **Перенесено**: условия стола («шершавый асфальт», «ветер», «золотой стол»)
  сознательно не вошли в S2 — под них нужен отдельный слой модификаторов,
  чтобы не ломать детерминизм. Кандидат в S4/S6.

## S3. Desktop и кросс-платформа — ✅ сделано

- **Клавиатура** (`src/game/ui/keymap.ts` + `Keys.ts`): `Space` — зажать и
  отпустить удар, `←/↑/↓/→` — сдвиг прицела, `1–3` — спец-удары
  (🎯 точный / 🛡 отбой / ⚡ двойной), `Esc` — подтверждение выхода,
  `F` — полный экран. Работает и в одиночной партии, и за онлайн-столом;
  клавиши не перехватываются при вводе текста (имена столов, ставки).
- **Hover + тултипы** (`src/game/ui/Tooltip.ts`): у фишек в стопке —
  вес и шанс перебить под текущим прицелом (без спойлера личности),
  в коллекции и маркете — полная карточка (редкость, серия, вес, ценность,
  количество). Отключаются тумблером «Подсказки».
- **Настройки** (`Settings.ts`, диалог в меню по ⚙): звук, анимации
  (`reduceMotion`), подсказки, размер экрана (`compact/normal/large`) и
  полный экран. Настройки живут в отдельном ключе `chips.settings.v1`.
- **PWA**: `manifest.webmanifest`, `icon.svg`, `maskable.svg`, `sw.js`
  (офлайн-оболочка, network-first для навигации), кнопка установки в
  боковой панели. SW регистрируется только в production-сборке.
- **Desktop-обвязка** (`index.html` + `styles.css` + `Shell.ts`): портретный
  канвас по центру, боковые панели с подсказками и фуллскрином, скрываются
  на узких экранах; `data-ui-size` управляет высотой канваса.
- Проверки: `tsc` чисто, **48** клиентских тестов (включая `sanitizeSettings`
  и `keyActionFor`), 18 серверных, 23 онлайн-проверки, `npm run build`.
  В браузере проверены клавиатура, `Esc`-подтверждение, тултипы, диалог
  настроек и адаптивная обвязка (1200 px vs 800 px).

## S4. Мета — ✅ сделано

- **Серии коллекции** (`src/game/data/Series.ts` + `systems/Series.ts`): прогресс
  `собрано/всего` + одноразовая награда за полную серию (`25×n + 20×epic + 50×legendary`),
  авто-выдача через `syncSeries` при любом пополнении коллекции, хранение
  `seriesClaimed`. UI — модалка «СЕРИИ» в коллекции.
- **Ежедневные задания** (`src/game/data/Quests.ts` + `systems/Quests.ts`): 3
  задания в сутки, детерминированный роул от даты (`hash(YYYY-MM-DD)`),
  прогресс `wins / flips / special / sells / wheel / unique`, клейм награды.
  Счётчики тикают в `settleMatch` (победы/выбитые/спецы/найденные), `sellChip`,
  `spinWheel`. Фаucет в меню — третья карточка «ЗАДАНИЯ».
- **Кузница** (`src/game/systems/Forge.ts` + `FORGE` в Constants): очки =
  `Σ (count−1)×value`, крафт = `ceil(price/5)`, апгрейд = `20 + 12×(level−1)`,
  макс. уровень 5; эффективные статы `power×(1+0.08×(lvl−1))`, `rare+0.005×(lvl−1)`.
  Уровень попадает в `PlayerState.bitaLevel` и на сервер (приветствие/стол).
- **Глобальный рейтинг**: `GET /api/leaderboard` + `POST leaderboard:submit`
  (лучший результат на аккаунт), табы «ГЛОБАЛЬНЫЙ / ЛОКАЛЬНЫЙ» в
  `LeaderboardScene`.
- Профиль: `PROFILE_VERSION = 2` (`bitaLevels`, `seriesClaimed`, `quests`), миграция v1.
- Проверки: `tsc` чисто, **63** клиентских тестов (новые: series/quests/forge,
  миграция профиля), 20 серверных (новые: forge-level в `powerOf`, уровень в room),
  онлайн-смоук, `npm run build`.
