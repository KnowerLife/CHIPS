# ADR-0001: Web stack choice

*Status: Accepted · Date: 2026-10-14*

## Context

Нужна кроссплатформенная веб-игра по мотивам «соток», с минимальной ценой поддержки, быстрой итерацией и возможностью юнит-тестировать игровую логику отдельно от рендера.

## Decision

Использовать **Phaser 3 + TypeScript + Vite**, тесты — **Vitest**.

## Rationale

- **Phaser 3** — зрелый 2D-движок (Scenes, Tweens, Graphics, Containers), идеален для мини-игр; рендер в canvas/WebGL.
- **TypeScript** — строгая типизация, соответствует стандартам проекта.
- **Vite** — мгновенный dev-сервер и простая статическая сборка (`base: './'` для переносимого бандла).
- **Чистое ядро** — `src/game/systems/*` не импортирует Phaser, поэтому логика тестируется Vitest без DOM.
- **Scale.FIT + 480×800** — один билд на desktop/mobile/tablet.

## Considered alternatives

| Вариант | Почему не выбран |
| --- | --- |
| Godot 4 Web Export | Тяжёлая HTML5-сборка, сложнее тестировать чистую логику в JS-окружении |
| Vanilla TS + Canvas | Больше ручной работы (сцены, твины, ввод) |
| PixiJS | Отличный рендер, но меньше «игровых» удобств |
| React + Phaser | Избыточно для игрового экрана |

## Consequences

- **Плюсы:** быстрая итерация, простые тесты, предсказуемый билд, дешёвый деплой статики.
- **Минусы:** engine-специалисты шаблона (Godot/Unity/Unreal) неприменимы; применимы системные и UI-агенты.
- Стек явно зафиксирован в `technical-preferences.md`, этом ADR и README.
