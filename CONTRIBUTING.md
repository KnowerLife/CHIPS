# Contributing to CHIPS

Спасибо за интерес к проекту! **CHIPS** — веб-игра по мотивам дворовых «Соток/Фишек», и мы рады идеям, баг-репортам и улучшениям.

## Как помочь

- **Баги:** создайте issue по шаблону *Bug report* с шагами воспроизведения, окружением и (по возможности) скриншотами/логами.
- **Идеи и фичи:** создайте issue по шаблону *Feature request*. Пожалуйста, учитывайте, что базовые правила «Соток» и баланс меняются осторожно.
- **Код/документация:** форкните репозиторий, создайте ветку, внесите изменения и откройте Pull Request.

## Локальная разработка

```bash
npm install
npm run dev:all      # Vite (5173) + игровой сервер (8787)
```

Полезные команды:

```bash
npm run typecheck    # проверка типов
npm test             # тесты клиента (vitest)
npm run test:server  # тесты сервера (node --test)
npm run build        # production-сборка в dist/
npm run smoke        # e2e-проверка онлайна (нужен запущенный сервер)
```

## Принципы изменений

- **Не менять правила «Соток»** без явного обсуждения; геймплейные значения — data-driven.
- Сохранять консистентность с существующей структурой, стилем и паттернами кода.
- Чистая логика игры живёт в `src/game/systems/*` и `server/engine.mjs` — предпочитайте покрывать её тестами.
- UI/UX: элементы должны быть кликабельны по всей области, верстка — без наложений (особенно на мобильных).
- Не коммитьте секреты, `.env`, runtime-данные (`server/data/`), `node_modules/`, `dist/`.

## Pull Request

- Опишите, **что** и **зачем** изменено, и как это проверялось.
- Приложите скриншоты/видео для визуальных изменений.
- Перед PR желательно прогнать: `npm run typecheck && npm test && npm run test:server && npm run build`.
